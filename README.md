# Spring Boot REST API Exercise

A simple backend project created using Spring Boot to practice REST API development.

## Technologies
- Java
- Spring Boot
- IntelliJ IDEA
- Postman

## Project Structure
- Model – Represents the data
- Service – Contains the business logic
- Controller – Handles API requests

## API Testing
The API was tested using Postman.


## What I Practiced
- Creating a Spring Boot backend
- Building REST APIs
- Using Controller, Service, and Model layers
- Testing APIs with Postman
